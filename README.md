# QR-generator

PC 端二维码工作台 **QR Studio Pro**（Vite + React 19 + TypeScript + Tailwind CSS 4）。设计稿参考目录 `stitch_modern_qr_studio/`。

## 开发与构建

```bash
pnpm install
pnpm dev
pnpm run build
```

产物：`dist/`。部署说明见 [`DEPLOY.md`](DEPLOY.md)。
